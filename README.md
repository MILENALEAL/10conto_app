# 💰 10Conto

Um web app simples e direto ao ponto para organizar as finanças pessoais. Criei o **10Conto** para ter um lugar prático onde lançar os gastos do dia a dia, sem a complexidade daquelas planilhas gigantes. 

## 🚀 O que o app faz?

* **Sistema de Contas:** Cadastro e login seguros. Cada usuário tem seu próprio espaço e só enxerga os próprios gastos.
* **Dashboard Intuitivo:** Resumo rápido do total gasto no mês logo na tela inicial.
* **Histórico por Mês:** Filtro fácil para navegar pelos meses anteriores e comparar despesas.
* **Tabelas e Categorias:** Separação automática dos gastos (Alimentação, Transporte, Lazer, etc.) para saber exatamente para onde o dinheiro está indo.
* **Painel Admin:** Uma área restrita (acessível apenas por mim) para gerenciar o sistema e visualizar o total de usuários ativos.

## 🛠️ Tecnologias Utilizadas

* **Back-end:** Python + Flask
* **Banco de Dados:** SQLite (com SQLAlchemy)
* **Autenticação:** Flask-Login
* **Front-end:** HTML5, CSS3 puro e Jinja2 (100% responsivo para funcionar bem no celular)
* **Hospedagem:** PythonAnywhere
